MUSTANG PERFORMANCE LAB — SOUND ASSETS

These WAV files are ORIGINAL SYNTHETIC PLACEHOLDER engine-style sounds created
for the frontend prototype. They are NOT recordings of real Ford Mustang engines.

Engine families:
- ecoboost: 2.3L turbo four-cylinder style
- gt: 5.0L naturally aspirated V8 style
- dark-horse: 5.0L naturally aspirated V8 performance style
- dark-horse-sc: supercharged 5.2L V8 style

The same sound family can be reused by variants with the same engine.
For a public submission, replace these placeholders with audio you have a
license/permission to publish. Do not rip copyrighted audio from YouTube.
